# weather-etl-pipeline

A small batch ETL pipeline: pull public weather data from the
[Open-Meteo](https://open-meteo.com/) API, clean and validate it, load it
into a local SQLite database, and run data-quality checks.

Python-only. No cloud accounts, no API keys.

## Status

Work in progress — project skeleton only so far. Usage instructions will
be added once the pipeline is functional.
